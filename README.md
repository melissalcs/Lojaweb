# Style Store

Projeto de uma loja virtual desenvolvido como atividade de aula de Front-End, utilizando HTML, CSS e JavaScript.

## 📌 Sobre o projeto

A **Style Store** é uma loja virtual fictícia que apresenta produtos divididos em categorias feminina, masculina e infantil.

O projeto possui páginas para clientes e vendedores, além de recursos interativos para navegação, exibição de produtos e gerenciamento do carrinho de compras.

## 🚀 Funcionalidades

- 🏠 Página inicial com produtos em destaque
- 🎞️ Carrossel de banners com navegação automática
- 👗 Categorias feminina, masculina e infantil
- 🛍️ Vitrine de produtos
- 🛒 Carrinho de compras flutuante
- 📋 Modal para visualização dos itens do carrinho
- 💰 Cálculo do valor total da compra
- 👤 Área do cliente
- 🏪 Área do vendedor

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
